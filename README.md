# AUREON FIELD

**Public coherence instrument.** Private by design. Free to use.

Live site: [https://aureon-field.netlify.app](https://aureon-field.netlify.app)

AUREON FIELD is a browser-based digital wellness instrument. It combines a living visual field, restorative tones, spoken-word practice, an optional ambient sentinel, and a local companion. No account. No backend required. State stays in your browser.

## Use it in 60 seconds

1. Open the live site (or open `index.html` locally).
2. Click **Initialize Field**, then **Restoration Tones**. Browsers need a tap before audio can play.
3. Pick Focus / Earth / Release, or a spoken practice (Calm, Attention, Rest, Gratitude).
4. Optionally start **Interval Voice** and **Sentinel**. Sentinel uses the microphone only after you allow it.

Keep the tab open if you want intervals to continue.

## What is included

- Living visualizer (wave, orbit, spectrum, lattice)
- Frequency studio with 528 / 432 / 396 presets
- Robust spoken-practice queue (Web Speech API)
- Optional microphone sentinel for sudden loud spikes
- Local companion that can start, explain, and repair features
- Phrase vault + session persistence in `localStorage`

## Honest disclaimer

This is a digital wellness and attention tool. It is **not** medical care, physical security, legal protection, or a guaranteed supernatural shield. Use it as a practice for focus, rest, prayer, or reclaiming attention.
